01 / THE CONTEXT

The business question

Where is sales volume meeting its target, and which depots and customer groups drive performance?

02 / THE BUILD

Approach & dashboard features

  1. Presented sales, actual volume, target achievement and returns in an overview dashboard.
  2. Connected monthly trends to a report tooltip with actual, target and returns detail.
  3. Used a supervisor → route → representative hierarchy to support performance drill-down.

03 / THE ANSWER

What the data shows

01

Actual volume exceeds target by 247,505.68 kg.

02

Riyadh contributes 69.65% of displayed depot sales; Othaim contributes 43.12% of customer-group sales.

03

Returns of 289,612 kg equal 2.63% of actual volume, using returns divided by actual volume.

04 / THE NEXT STEP

Recommendations

  • Investigate below-target supervisors and routes using the performance matrix.
  • Monitor returns alongside sales volume and target achievement.
  • Review the concentration of sales across depots and customer groups.

EVIDENCE & SCOPE

How to read these findings

Values describe the supplied dashboard snapshot. Its reporting period and filter context are not visible. Saved measure references and visual configuration were inspected; DAX expressions and native refresh were not verified.

The dashboard image is a supplied snapshot. This website presents the case study; interactive analysis is performed in the native Excel or Power BI file.
